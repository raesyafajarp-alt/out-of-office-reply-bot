# Out-of-Office Reply Bot

Entry for make.fun competition
`u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8` —
"Funniest One-Line Out-of-Office Reply".

## The entry

> I'm out of the office until Monday — my inbox is unsupervised, and so am I.

(78 characters, one line.)

## What the program does

`main.py` writes that single out-of-office reply to `/output/entry.txt`.
Nothing else: no network, no input files, no secrets.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3. The output file is UTF-8 text, one line, 1–160 characters.
